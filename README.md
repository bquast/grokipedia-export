# Grokipedia-export

Export Grokipedia articles to wikitext plain text files.

1. open the article on Grokipedia
2. open the browser console (ellipsis menu > More Tools > Developer Tools > Console)
3. paste the script in the console
4. follow the warning instructions if needed (e.g. type: allow pasting)
5. choose desired filename
